# Fresh-Check
FreshCheck is a web tool that checks if an apple is fresh or bad using your camera or an image file. It runs directly inside the browser using JavaScript and TensorFlow.js, so your photos stay on your device.

What it does
Checks apples using a photo or your live webcam

Shows if the apple is fresh or rotten with a score percentage

Tracks your previous scans so you can see past results

Shows total counts for fresh and bad apples that update automatically

Lets you search, delete, or download your scan history as a file

Tools used
HTML and CSS for the page layout

Vanilla JavaScript for the app logic

TensorFlow.js to run the image model in the browser

Google Teachable Machine for the apple model

How to run it
Download or clone this repository to your computer

Open index.html in any modern web browser

Allow camera access if you want to use the live scan feature

How to use it
Click Choose Image to pick an apple photo from your device, or drag and drop an image into the box

Click Take a Photo if you want to use your webcam

View the result on the right side of the screen

Open the History tab to look at old checks or clear them
